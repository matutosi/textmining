# 構想: 文のつながりで論理構造を可視化するパッケージ

(2026-08-04 記録．textmining2 とは別プロジェクトだが，
置き場所が決まるまで暫定的にここに置く)

## 目的

単語のつながりによって，文章の論理的な構造を明確にする R パッケージを作る．

- 前方の文と同じ単語があれば，その単語でつなげて文章を表示する．
- 前方(および後方)の文と共通の単語がまったくない文は，
  プログラミングでのデッドコードと同じとみなして検出する．

### 表示のイメージ(ユーザ提供の例)

```
文章とは，単語のつながりである．
               (つながり)があるおかげで，文章の構造を明示できる．
                                              (構造)がわかれば，文章を理解しやすくなる．
```

## 段階

1. **R パッケージを完成させる** ← 今ここ
2. Python へ移植する(Streamlit を使う予定)
3. 文章のわかりやすさの判定．段落内での各文の意図を構造化して示し，
   構造化の程度を判定する．ラベルの例:
   トピックセンテンス / 理由 / 補足 / 例示

## 決定事項

- **「同じ単語」の判定**: 形態素解析を通し，名詞・動詞・形容詞などの
  内容語に絞り，**原形(語彙素)で比較**する．
  「つながる」と「つながり」は同一とみなす．助詞・記号は無視する．
- **さかのぼる範囲**: **段落内のすべての先行文**を対象とする．
  ただし**近い文とのつながりほど良い**という基準を加える
  (距離を評価に反映させる)．
- **代表の選び方**: 1つの文が複数の先行文・複数の単語とつながるとき，
  **その文の中でより前方に現れる単語**を代表とする．
  あわせて，**最大3つまでつながりを示せるオプション**を用意する．
- **距離の扱い**: 距離そのもの，または距離の逆数．どちらを使うかはオプションとする．
- **入力**: プレーンテキストと Markdown．
  Markdown はプレーンテキストに変換してから解析する．
  文の区切りはピリオドと句点(`.` `．` `。`)．
- **形態素解析**: ローカル実行が基本(MeCab / Sudachi / Ginza)．
  ネットワークに依存しない構成にする．
- **対象言語**: 当面は日本語のみ．
- **デッドコードの検出**: 孤立した文を挙げるだけでなく，
  段落を「単語の共有グラフ」とみなして**連結成分**を数える．
  成分が2つ以上あれば，その段落は話の繋がらない箇所で割れていると判定できる．
  段階3の「構造化の程度」の指標にも使う．
- **置き場所**: 保留(新規リポジトリ / この textmining 内 / moranajp に追加)．
- **2回目に現れた単語の表示**: 保留．
  色や装飾で区別する案，線でつなぐ案が有力．
- **段階3のラベル付けの手段**: 検討中
  (接続表現によるルールベース / LLM / 人手アノテーション)．

## 課題

- **moranajp の CRAN アーカイブ**．
  moranajp は 2025年半ば頃(2026-08-04 時点で約1年前)に CRAN からアーカイブされた．
  <https://cran.r-project.org/web/packages/moranajp/index.html>
  原因はユーザから別途共有される予定．
  - このパッケージを CRAN に出すなら，**CRAN 上の moranajp に依存できない**．
    アーカイブ理由を解消して再登録するか，形態素解析の部分を
    このパッケージ内に持つか，方針を決める必要がある．
  - アーカイブの理由は，このパッケージでも同じ形で再発しうる．
    理由が分かった時点で，設計に反映する．
